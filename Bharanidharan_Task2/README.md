# Customer Segmentation Analysis

## Objective
Segment e-commerce customers based on purchasing behavior using RFM analysis and K-Means clustering.

## Tools Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

**Dataset Name:** Online Retail Dataset

**Source:** Kaggle

**Dataset Link:** https://www.kaggle.com/datasets/ulrikthygepedersen/online-retail-dataset

The dataset is not included in this repository due to GitHub's browser upload size limit.

## Project Overview
- Data cleaning and preprocessing
- RFM analysis
- Feature scaling
- Elbow Method and K-Means clustering
- Silhouette Score evaluation
- Customer segmentation and visualization
- Marketing insights and recommendations

## Customer Segments
- Cluster 0: Inactive Customers
- Cluster 1: Loyal Customers
- Cluster 2: VIP Customers
